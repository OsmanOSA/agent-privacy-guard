Public status claims require evidence linked from the compatibility matrix. A design, a unit test and an observed real-agent result are different kinds of evidence. Keep their labels explicit.

The PRD is a vision archive. Product scope changes go in the product brief; terminology changes go in the glossary; durable trade-offs go in an ADR; implementation tasks go in the local tracker.
